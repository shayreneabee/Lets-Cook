# World country boundaries

`world-countries-110m.json` is the `countries-110m.json` dataset from
[world-atlas version 2](https://github.com/topojson/world-atlas), generated from
the [Natural Earth 1:110m Admin 0 Countries](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/)
dataset.

Natural Earth data is in the public domain. The world-atlas packaging code is
distributed under the BSD 3-Clause license. The data file is stored locally so
the globe remains available without a third-party runtime request.
